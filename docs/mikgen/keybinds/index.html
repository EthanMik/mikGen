Segment Interfacing

Reference for adding, selecting, and editing segments.

Adding Segments​

Similar segments share the same keybinds across every format, but each format only offers the segments its library supports. You can use the Segment dropdown to add them:

Keybinds​

Pressing these keybinds on the field will place desired segment

ButtonSegmentDescription
Left ClickpointDriveDrives the robot to desired (x, y)
Ctrl + Left ClickposeDriveDrives robot to desired (x, y, theta)
Alt + Left ClickdistanceDriveRelative motion, drives specified distance based on heading before it
Ctrl + Alt + Left ClickstrafeDriveSame as distanceDrive but moves left and right
Right ClickpointTurnPoints to drive segment in front of it
Ctrl + Right ClickangleTurnTurns to specified angle
Alt + Right ClickpointSwingSwings a drivetrain side to drive segment in front of it
Ctrl + Alt + Right ClickangleSwingTurns a side of drivetrain to specified angle
important

New segments are inserted after the currently selected segment, otherwise they are appended to the end of the path.

Selecting Segments​

ActionEffect
Left ClickSelect a segment
Ctrl + ClickAdd or remove a segment from the selection
Shift + Click on path listSelect a range
Click + Drag on fieldBox select
Ctrl + ASelect all
Ctrl + Shift + AInvert selection
EscDeselect all
note

If a turn or wait segment is on top of a drive segment, you can click on the drive segment again to select it.

Editing Segments​

ActionEffect
DragMove the segment on the field
Ctrl + DragSnap to grid (grid size set in Settings, default 0.5 in)
Shift + DragAlign segment to another one
Arrow KeysNudge selected segments 0.25 in
Shift + Arrow KeysNudge selected segments 1 in
Shift + ScrollRotate heading in 90 degree snaps
Ctrl + Shift + ScrollRotate heading in 5 degree steps
Backspace / DeleteDelete selected segments
Drag row in path listReorder segments
Ctrl + ZUndo
Ctrl + YRedo

View​

You are able to collapse the left bar ()

ActionEffect
Space + DragPan the field
Middle Click + DragPan the field
ScrollPan the field
Ctrl + ScrollZoom toward the cursor
Ctrl + = / Ctrl + -Zoom in / out
Ctrl + 0Reset zoom

Playback Controls​

ActionEffect
Space or KPlay / Pause simulation
J / LScrub backward / forward 0.01 second
Shift + J / LScrub backward / forward 0.25 second
RToggle robot visibility
;Toggle simulation looping
Right Click segment on path listJump the simulation to that segment

Number Inputs​

ActionEffect
Scroll wheelIncrease / Decrease
Click and drag sidewaysIncrease / Decrease

Settings​

ActionEffect
OToggle onion layers
PToggle precise path (Shows exact path robot took with speed colors)
